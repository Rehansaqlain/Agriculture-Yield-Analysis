# Agriculture Yield Analysis

## Project Overview

This project analyzes agricultural data to understand the factors that influence crop yield.

The analysis includes data cleaning, exploratory data analysis (EDA), visualization, correlation analysis, business-oriented insights, and machine learning for yield prediction.

## Objectives

* Clean and prepare agricultural data
* Explore relationships between agricultural factors and crop yield
* Identify important patterns and insights
* Create meaningful visualizations
* Extract useful business insights from agricultural data
* Build a machine learning model to predict crop yield

## Dataset

The dataset contains information related to:

* Region
* Soil Type
* Crop
* Rainfall
* Temperature
* Fertilizer
* Irrigation
* Weather
* Days to Harvest
* Yield

## Exploratory Data Analysis

The project explores:

* Yield distribution
* Rainfall and yield relationship
* Temperature and yield relationship
* Crop-wise yield
* Fertilizer and yield
* Irrigation and yield
* Weather conditions and yield
* Correlation between numerical variables
* Outlier analysis

## Machine Learning

A **Random Forest Regressor** was trained to predict agricultural yield.

### Model Evaluation

* **MAE:** 0.42
* **RMSE:** 0.52
* **R² Score:** 0.90

An **Actual vs Predicted** scatter plot is included to visualize the model's predictions.
